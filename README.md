# Ashutosh Dubey — Portfolio Template 2

Interactive/3D-inspired developer portfolio built with Next.js, TypeScript, Tailwind CSS and Framer Motion.

## Run
npm install
npm run dev

## Customize
- Replace `href="#"` project/social links in `app/page.tsx`.
- Add your PDF as `public/resume.pdf` if you want a resume download.
- Update project URLs and any copy as needed.
